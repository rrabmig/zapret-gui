# GUI for zapret

Независимый графический интерфейс для [zapret](https://github.com/bol-van/zapret), разработанного **bol-van**. GUI разрабатывает **rrabmig**; для работы он отдельно скачивает Windows-сборки и стратегии из [Flowseal/zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube). Код zapret, WinDivert и сборки Flowseal принадлежат их авторам; GUI for zapret не является их официальным интерфейсом.

GUI отвечает за скачивание и выбор сборки, настройки, списки и управление процессом или службой. Обработку трафика выполняет отдельно загруженный `winws.exe`. Версия GUI и тег сборки Flowseal — разные версии; в разделе «Сборки Flowseal» они показаны в отдельных блоках.

**Статус: первая версия для проверки на личном Windows-устройстве.** Локальные сборки, тесты и запуск движка на машине автора разработки намеренно не выполняются. GitHub Actions проверяет код и собирает GUI на удалённых runner’ах; работоспособность обхода у провайдера этим не подтверждается.

## Платформы

| Сборка | Интерфейс, настройки, пакеты | Запуск zapret из сборки Flowseal |
|---|---|---|
| Windows 10/11 x64 | Да | Да, через WinDivert, с правами администратора |
| macOS, Intel и Apple Silicon | Да | Недоступен: у Flowseal zapret из Windows-сборки |
| Linux x64 | Да | Недоступен: у Flowseal zapret из Windows-сборки |

Это выбранный вариант «поддерживать оболочку, минимально затрагивая upstream». Нативные Linux/macOS-движки в него не входят. Подробное сравнение вариантов — [docs/architecture.md](docs/architecture.md).

## Возможности

- Каталог `general*.bat` из выбранной сборки Flowseal, поиск и выбор стратегии. Прямой запуск доступен для стратегий, формат которых понимает GUI.
- Прямой запуск `winws.exe` без исполнения batch-скриптов при обычном запуске. Остановка только процесса, созданного GUI.
- Управление службой для отдельно загруженного zapret (технический ID `ZapretDesktop`): установка с автозапуском, запуск, остановка, удаление. Копия для службы хранится в защищённом `%ProgramData%\GUIForZapret`, с записью только для Administrators и SYSTEM.
- Game Filter: disabled / TCP / UDP / TCP+UDP, отдельные диапазоны портов.
- IPSet Filter: loaded / none / any, обновление списка и дополнительные пользовательские IP/CIDR.
- Редактор пользовательских доменов, исключений доменов и IP, целей Standard tests.
- Выбор Discord UDP и Game UDP fake-файлов из `bin` текущего релиза.
- Проверка стабильных GitHub Releases, установка с SHA-256, переключение установленных версий и откат.
- Предпросмотр hosts; отдельное применение в маркированный блок, с резервной копией оригинала.
- Диагностика локального состояния без исправлений; кэш Discord сохраняется в резервных папках.
- Оригинальные **Standard tests / DPI checkers** и всё меню **service.bat** открываются отдельно по явной команде. Встроенной копии их логики нет.
- Журнал, светлая/тёмная/системная тема, отсутствие внешних шрифтов и веб-ресурсов в интерфейсе.

Сопоставление возможностей GUI и утилит Flowseal: [docs/features.md](docs/features.md). Часть редких функций доступна через оригинальное меню, а не через отдельные GUI-контролы.

## Первый запуск на личном Windows-устройстве

1. Стабильные версии публикуются в [GitHub Releases](https://github.com/rrabmig/zapret-gui/releases). Если опубликованных версий пока нет, откройте [GitHub Actions](https://github.com/rrabmig/zapret-gui/actions/workflows/build.yml), выберите успешный запуск ветки `main` и скачайте артефакт `zapret-gui-windows-amd64`. Для private-репозитория нужен вход с доступом к нему. Распакуйте ZIP артефакта и запустите `GUIforzapret-Setup-<версия>-x64.exe`. Установщик добавит **GUI for zapret** в меню «Пуск» и при необходимости установит Microsoft Edge WebView2 Runtime. Ссылка «GUI» в боковом меню открывает репозиторий приложения; сборки находятся во вкладке Actions.
2. Откройте **GUI for zapret** через меню «Пуск». zapret не запущен; установки драйвера и запуска стратегий при открытии нет.
3. В «Сборках Flowseal» скачайте стабильную сборку Flowseal и отдельно примените её. Проверьте выбранную стратегию и пользовательские списки.
4. В «Настройках» включите «Разрешить запуск zapret», сохраните и нажмите «Запросить права». GUI перезапустится после UAC.
5. Нажмите «Запустить». Работоспособность стратегии зависит от сети. Проверки стратегий и DPI запускаются отдельно.
6. При необходимости установите службу автозапуска. После её установки закрытие GUI не останавливает службу.

Смена стратегии, фильтров, списков, обновление и откат требуют остановить процессы и удалить установленную службу. Это исключает замену файлов действующего движка. Сначала запросите права, затем удалите службу; после настройки установите её снова.

Если обнаружена чужая установка `zapret` или сторонний `winws.exe`, GUI блокирует запуск и изменение рабочих файлов. Для управления чужой установкой используйте её исходный инструмент.

## Как устроены обновления

**GUI:** отдельная проверка, opt-in проверка при открытии, скачивание проверенного Windows Setup и «Обновить и перезапустить» после подтверждения. Настройки/пакеты сохраняются; служба не переустанавливается. Запускайте обновление из GUI без прав администратора. На macOS/Linux — ручная установка со страницы релиза. Старое приложение без updater один раз обновляется вручную. Полное описание и выпуск новых версий — [docs/gui-updates.md](docs/gui-updates.md).

**Сборки Flowseal:**

GUI обращается к `Flowseal/zapret-discord-youtube/releases/latest`, выбирает ZIP из релиза Flowseal, проверяет размер и опубликованный GitHub SHA-256. Если digest отсутствует, автоматическая установка прекращается. HTTPS и checksum защищают доставку, но не заменяют подпись автора и не защищают от компрометации самого upstream.

Архив распаковывается во временный каталог с ограничениями размера, числа файлов и проверкой путей. После проверки структуры новый пакет появляется в `versions/<tag>`. Скачивание не переключает выбранную версию: она применяется отдельно в разделе «Сборки Flowseal». При сетевой ошибке или несовпадении checksum текущая версия остаётся прежней. Предыдущие пакеты сохраняются.

Проверка при открытии включается отдельно и скачивает только метаданные. Автоматических установок и запусков нет. Проверка исходных стратегий в CI позволяет заметить изменение их формата; оригинальное меню сохраняет доступ к upstream без переписывания функций.

Из `main` отдельно берутся только неисполняемые данные `.service/ipset-service.txt` и `.service/hosts`, после нажатия соответствующей кнопки. Исполняемые файлы из движущейся ветки не обновляются.

## Данные

По умолчанию:

- Windows: `%APPDATA%\GUIForZapret`
- macOS: `~/Library/Application Support/GUIForZapret`
- Linux: `$XDG_CONFIG_HOME/GUIForZapret` или `~/.config/GUIForZapret`

```text
config.json                 настройки GUI и указатели версий
runtime/<tag>/              пересоздаваемая рабочая копия
overrides/                  пользовательские списки и свежий IPSet
app.log                     локальный журнал
```

В Windows скачанные пакеты находятся рядом с EXE: `%LocalAppData%\Programs\GUIForZapret\versions\<tag>`. На macOS/Linux — в `versions/<tag>` внутри каталога данных. Это полные релизы сборки Flowseal с бинарником zapret, WinDivert, библиотеками и стратегиями. Миграции из прежнего `packages` нет.

`--data-dir <каталог>` задаёт другой каталог настроек и рабочих копий; в Windows путь `versions` по-прежнему определяется относительно EXE, а не текущего каталога. Для службы GUI отдельно создаёт защищённую копию в `%ProgramData%\GUIForZapret`. Удаление службы не удаляет эту копию, пакеты и настройки. Удалять их можно после остановки и удаления службы.

Настройки из оригинального `service.bat` действуют в рабочей копии. При следующем управляемом запуске GUI пересоздаёт её из пакета из релиза Flowseal и применяет свои настройки. Изменения, сделанные вручную внутри `runtime`, не являются постоянными. Открытое оригинальное окно блокирует управляемые изменения до завершения сеанса.

## Сборки и проверки

В репозитории настроен [GitHub Actions](.github/workflows/build.yml):

1. Unit-тесты и race detector для ядра на Windows/Linux/macOS, без запуска движка.
2. Чтение всех стратегий и проверка реальной установки, выбора и подготовки рабочего дерева ZIP из релиза Flowseal на Linux/Windows runners. Бинарники извлекаются только во временный каталог runner и никогда не запускаются.
   Интерфейс проверяется отдельно в Chromium с неисполняемой заглушкой Go-моста; сравнения скриншотов обеих тем, HTML-отчёт Playwright и собранный Storybook доступны в артефакте `frontend-review`.
3. Сборки `windows/amd64`, `darwin/universal`, `linux/amd64` с Wails v2.15.0.
4. Windows Setup EXE и ZIP для macOS/Linux, в артефактах Actions; стабильные версии публикуются отдельно в Releases. Тег `v*` создаёт draft release после успешных сборок и проверки совместимости.

Зависимости: Go 1.25+, Node.js 24 и Wails CLI v2.15.0. Интерфейс — React + TypeScript + Vite, стили компонентов — CSS Modules. Wails выполняет `npm ci --ignore-scripts` и `npm run build`, затем встраивает только `frontend/dist` в приложение. На Linux нужны GTK3 и WebKitGTK 4.1, для macOS — Xcode Command Line Tools. Команды ниже предназначены для подходящего устройства или CI:

```sh
go install github.com/wailsapp/wails/v2/cmd/wails@v2.15.0
wails build
# Linux / WebKitGTK 4.1:
wails build -tags webkit2_41
```

Пакеты GUI пока без code signing / notarization и без автоматического обновления самой оболочки. Билд не открывает окно и не запускает движок; генерация Wails bindings использует отдельную точку входа без инициализации приложения. Полная проверка WinDivert, служб и обхода должна выполняться отдельно на личном Windows-устройстве: [docs/validation.md](docs/validation.md).

Разработка интерфейса, дизайн-система, Storybook и обновление визуальных эталонов: [docs/frontend.md](docs/frontend.md).

## Установка Windows

Скачайте `GUIforzapret-Setup-<версия>-x64.exe` из GitHub Releases или артефакта `zapret-gui-windows-amd64`. Установщик NSIS устанавливает GUI для текущего пользователя в `%LocalAppData%\Programs\GUIForZapret`, создаёт ярлык в «Пуск» и запись в «Установленных приложениях» с издателем **rrabmig**. На странице «Параметры установки» есть необязательный флажок «Создать ярлык на рабочем столе», выключенный по умолчанию. При необходимости установщик скачивает Microsoft WebView2 Runtime. Сам zapret не входит в установщик и скачивается из GUI.

Повторный запуск Setup обновляет GUI, сохраняя `versions`, настройки и пользовательские списки. Перед установкой/удалением закройте GUI и оригинальные утилиты. Если установлена служба `ZapretDesktop`, перед удалением приложения остановите и удалите её через GUI. Удаление приложения в таком случае блокируется, а не оставляет фоновую службу без управления. По умолчанию версии и данные сохраняются; полное удаление выбирается отдельными флажками. Тихое удаление `/S` сохраняет данные.

Метаданные GUI и Setup содержат `CompanyName=rrabmig`. Это не Authenticode-подпись: UAC/SmartScreen могут по-прежнему показывать неизвестного издателя. Файлы upstream не переименовываются и не получают метаданные автора GUI.

Обновление GUI из GitHub Releases, выпуск версий и ограничения доверия: [gui-updates.md](docs/gui-updates.md).

## Технические имена существующих установок

Пользовательское имя продукта — **GUI for zapret**, исполняемый файл — `GUIforzapret.exe`, установщик — `GUIforzapret-Setup-<версия>-x64.exe`. При обновлении прежний EXE и старые ярлыки заменяются новыми. `CompanyName=rrabmig` относится к GUI и его Setup; авторство zapret/сборок/драйвера этим не меняется.

Технические ID `ZapretDesktop` в SCM, mutex, ключе деинсталляции и маркерах hosts остаются стабильными. Каталоги приложения/настроек/службы называются `GUIForZapret`; данные из прежних каталогов не переносятся. Новая служба отображается как `zapret (GUI for zapret)`.

## Боковое меню, селекты и каталог установки

Под названием GUI указана ссылка на zapret-discord-youtube. Внизу бокового меню отдельным столбиком расположены ссылки на репозитории GUI, zapret-discord-youtube и zapret. В desktop ссылки открываются в системном браузере по нажатию пользователя.

Каталог установки Windows — `%LocalAppData%\Programs\GUIForZapret`, настройки — `%AppData%\GUIForZapret`, защищённая копия службы — `%ProgramData%\GUIForZapret`. На macOS/Linux каталог данных тоже называется `GUIForZapret`. WebView2 хранит данные внутри каталога настроек в `WebView2`. Переноса из старых каталогов нет: новая версия начинает с чистыми настройками и сборками; старые каталоги автоматически не удаляются.

Селекты используют нативный HTML-контрол с общей стрелкой и отступами; поддерживающие `appearance: base-select` WebView также получают оформленный в теме приложения раскрытый список. На старых WebView сохраняется штатный системный список и рабочая клавиатура.
