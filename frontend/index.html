Открыть сборки для Windows, macOS и Linux ↗

Выберите успешный запуск и прокрутите страницу до Artifacts, затем скачайте архив для своей ОС. Распакуйте скачанный архив и ZIP внутри него. Артефакты хранятся 14 дней.

Интерфейс доступен на этой ОС. Движок Flowseal требует Windows и WinDivert; запуск, системные службы и сетевые тесты здесь недоступны.

Оболочка использует целый официальный релиз, без fork и submodule. Проверка обновлений не устанавливает пакет. Настройки и пользовательские списки хранятся отдельно. Если формат стратегий изменится, останется оригинальное меню.
