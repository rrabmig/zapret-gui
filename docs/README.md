## Где выполнять проверки

На корпоративной машине разработки **не запускать приложение, zapret/winws, service.bat, тесты стратегий, DPI checkers, установку WinDivert, службы или изменения сети**. Локально также не выполняются компиляция, unit-тесты, GUI-тесты и превью. Разрешены чтение и редактирование исходников, документация, форматирование и необходимые зависимости без запуска приложения. Локальный Storybook с инертным мостом возможен только по отдельному явному запросу автора.

Сборки и автоматические проверки выполняются на удалённых GitHub runners. Реальная работа движка, UAC, службы и обхода проверяется только на личном Windows-устройстве. Инертные фикстуры и успешный CI не доказывают работоспособность обхода в сети пользователя.
