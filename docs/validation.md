# Граница проверки

На корпоративной машине разработки **не запускать приложение, winws, service.bat, тесты стратегий, DPI checkers, установку WinDivert, службы или изменения сети**. По запросу пользователя локально также не выполняются компиляция, unit-тесты и GUI-проверки. Разрешённая подготовка исходников ограничивается чтением документации, редактированием, форматированием и загрузкой зависимостей.

## Что делает GitHub Actions

- Unit-тесты конфигурации, портов, списков, семантики IPSet, разделения оригиналов и рабочей копии.
- Проверки ZIP traversal, symlink, Windows-имён и дубликатов без учёта регистра.
- Тесты обновлений через loopback HTTP fixtures: SHA-256, размер, повторная установка, сетевые ошибки, отсутствие неявной активации.
- Проверки разбора аргументов: пробелы в путях, batch-переменные, shell-операторы, неизвестный формат.
- Идемпотентное обновление маркированного блока hosts и сохранение пользовательских строк.
- Чтение текста всех стратегий официального последнего stable-релиза. Из ZIP извлекаются только `general*.bat`, исполняемые файлы не записываются и не запускаются.
- Сборка GUI для трёх ОС. Скомпилированное приложение в CI не запускается.
- Проверка интерфейса в Chromium с неисполняемой заглушкой Go-моста: opt-in, подтверждение сетевых проверок, блокировка на время оригинальных утилит, поиск стратегий, списки и недоступность Windows-движка на других ОС. Скриншоты обеих тем сохраняются как `ui-screenshots-fixtures`; это данные фикстуры, а не результат запуска WinDivert.

Эти проверки подтверждают работу загрузчика и контракта кода. Они не подтверждают работоспособность WinDivert, UAC, Windows-службы, WebView/UI, конкретной стратегии или доступность сайтов у провайдера.

## Отдельная ручная проверка на личном Windows-устройстве

1. Открытие GUI не запускает winws, не создаёт службу и не отправляет сетевые запросы при выключенном AutoCheck.
2. Установка официального пакета показывает все стратегии и .bin-файлы, но не запускает их.
3. При отказе UAC исходное окно остаётся открытым. При согласии открывается один повышенный экземпляр с теми же настройками.
4. Процесс запускается с выбранной стратегией, корректными путями с пробелами и настройками фильтров. Ошибка WinDivert видна в журнале.
5. «Остановить» завершает свой процесс. Сторонний winws и чужие службы не завершаются.
6. Служба устанавливается в ProgramData с защищённым ACL, запускается, работает после закрытия GUI и после перезагрузки, останавливается и удаляется из GUI после UAC.
7. Обновление/откат/смена списков блокируются при действующем процессе, установленной службе и открытых оригинальных инструментах.
8. Смена версии сохраняет пользовательские списки и дополнительные IP. Ошибка загрузки сохраняет активный пакет.
9. Оригинальные Standard tests и DPI checkers доступны, используют выбранную рабочую копию; завершённый сеанс освобождает блокировку. При ограничении PowerShell policy GUI её не меняет автоматически.
10. Hosts обновляется после предпросмотра, создаёт backup, повторное применение не дублирует блок и сохраняет сторонние строки.
11. Кэш Discord переименовывается только после закрытия Discord. Резервные папки можно вернуть вручную, когда Discord закрыт.
12. Светлая/тёмная тема, клавиатура, ошибки, длительное скачивание, отсутствие сети и GitHub rate limit понятны пользователю.

На Linux/macOS проверяются окно и работа с пакетами/списками; запуск Windows-движка должен оставаться недоступным.
