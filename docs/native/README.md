# Нативная часть

[Документация](../README.md) · [Фронтенд](../frontend/README.md) · [Дистрибуция](../distribution/README.md)

Go и Wails отвечают за жизненный цикл GUI, настройки и списки, загрузку официальных пакетов Flowseal, разбор стратегий, запуск собственного процесса и управление службой Windows. Сам zapret и WinDivert поставляются отдельно их авторами.

- [Архитектура](architecture.md): платформы, границы компонентов, стратегии, блокировки, каталоги и авторство.
- [Возможности и соответствие upstream](features.md): что доступно напрямую и что открывается в оригинальных утилитах Flowseal.
- [Проверки](validation.md): ядро, реальный ZIP без исполнения и ручная проверка на личном Windows.

Основные исходники: `app.go`, `main.go`, `internal/core/`. Обновление самого GUI и установщик относятся к [дистрибуции](../distribution/README.md); контракт с React — к [фронтенду](../frontend/README.md).
