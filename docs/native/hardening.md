# План повышения надёжности

[Нативная часть](README.md)

Работы идут последовательно, отдельными логическими коммитами. Проверки выполняются только на GitHub runners; реальные WinDivert/UAC/обход — на личном Windows.

## 1. Процессы и длительные операции

- [ ] Учитывать PID собственной службы отдельно от посторонних winws.
- [ ] Выполнять сеть и диагностику вне общей блокировки состояния; добавить отмену и ограничение времени.
- [ ] Оставить остановку своего процесса/службы доступной во время операции.
- [ ] Проверить классификацию процессов, concurrent stop/snapshot и отмену при закрытии на инертных зависимостях.

## 2. Применение обновления GUI

- [ ] Проверять установленную версию до перезапуска.
- [ ] Ждать подтверждения готовности нового GUI; сохранять backup при ошибке или таймауте.
- [ ] Проверить нулевой exit Setup без установки, ранний выход нового GUI, подтверждение и восстановление.

## 3. Закрытие и ранние ошибки

- [ ] Подключить защиту несохранённых правок к нативному OnBeforeClose.
- [ ] Показывать ошибки до инициализации Wails с путём к проблемным данным; не сбрасывать настройки молча.
- [ ] Проверить сохранение/отмену выхода и неуспешную инициализацию без запуска движка.

## 4. Пакеты и получение состояния

- [ ] Показывать каталоги с повреждённой/отсутствующей release.json.
- [ ] Восстанавливать пакет через проверенное временное дерево с сохранением активного выбора и блокировок.
- [ ] Кэшировать каталог версий, обновляя его после изменений и явной перепроверки.
- [ ] Проверить восстановление, сбои замены и отсутствие повторного обхода при polling.

## Границы

Сохраняются тонкая оболочка над Flowseal, форматы настроек, отсутствие миграций старых каталогов, ручное подтверждение установки и запрет автостарта движка. Не входят новая система подписи, полностью фоновая установка, перенос на другие нативные движки и полное переустройство всех пакетов Go. Компоненты разделяются по мере исправлений, без дополнительных runtime-зависимостей.
