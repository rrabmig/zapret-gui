## Сборки и релизы

[Workflow Build desktop](https://github.com/rrabmig/zapret-gui/actions/workflows/build.yml) собирает Windows x64 Setup, macOS universal ZIP и Linux x64 ZIP. Установщик и пакеты включают README, лицензии и дерево `docs/` с той же относительной структурой.

Артефакты Actions доступны из соответствующего успешного запуска и хранятся 14 дней. Для скачивания нужен вход в GitHub. Стабильные опубликованные [Releases](https://github.com/rrabmig/zapret-gui/releases) доступны без входа и служат источником обновления GUI.

Тег `vMAJOR.MINOR.PATCH` после успешных проверок и сборок создаёт draft release с Setup, ZIP и `SHA256SUMS`. Публикация draft выполняется отдельно; последовательность — в [публикации версии](gui-updates.md#публикация-версии). Артефакт Actions и draft release не являются опубликованным обновлением.

## Установка Windows

Скачайте `GUIforzapret-Setup-<версия>-x64.exe` из GitHub Releases или артефакта `zapret-gui-windows-amd64`. Установщик NSIS устанавливает GUI для текущего пользователя в `%LocalAppData%\Programs\GUIForZapret`, создаёт ярлык в «Пуск» и запись в «Установленных приложениях» с издателем **rrabmig**. На странице «Параметры установки» есть необязательный флажок «Создать ярлык на рабочем столе», выключенный по умолчанию. При необходимости установщик скачивает Microsoft WebView2 Runtime. Сам zapret не входит в установщик и скачивается из GUI.

Повторный запуск Setup обновляет GUI, сохраняя `versions`, настройки и пользовательские списки. Перед установкой/удалением закройте GUI и оригинальные утилиты. Если установлена служба `ZapretDesktop`, перед удалением приложения остановите и удалите её через GUI. Удаление приложения в таком случае блокируется, а не оставляет фоновую службу без управления. По умолчанию версии и данные сохраняются; полное удаление выбирается отдельными флажками. Тихое удаление `/S` сохраняет данные.

Метаданные GUI и Setup содержат `CompanyName=rrabmig`. Это не Authenticode-подпись: UAC/SmartScreen могут по-прежнему показывать неизвестного издателя. Файлы upstream не переименовываются и не получают метаданные автора GUI.

Обновление GUI из GitHub Releases, выпуск версий и ограничения доверия: [обновление GUI](gui-updates.md).
