# Покрытие возможностей Flowseal

Основа инвентаризации: README и `service.bat` стабильного релиза **1.10.4**, прочитанные 1 ноября 2026 года. Каталог стратегий не зафиксирован на этой версии и загружается динамически.

| Возможность upstream | В этой оболочке | Отличия |
|---|---|---|
| Запуск всех general / ALT / FAKE / EXP | «Стратегии» → «Запустить» | Чтение параметров из официальных batch-файлов; запуск winws напрямую |
| Install Service | «Обзор» → «Установить» | Собственная служба `ZapretDesktop`, защищённая копия в ProgramData |
| Remove Services | Удаление своей службы; оригинальное меню для upstream-служб | GUI не удаляет чужие zapret/WinDivert и не завершает все winws по имени |
| Check Status | Постоянное состояние в «Обзоре»; «Диагностика» | Отдельно свой процесс, своя служба, внешний winws и legacy-служба zapret |
| Game Filter | «Настройки» | disabled / all / TCP / UDP; отдельные диапазоны TCP и UDP |
| IPSet Filter | «Настройки» | loaded / none / any с исходной семантикой |
| Auto-Update Check | «Настройки» | Проверка релиза при открытии GUI, opt-in; без фонового запуска batch |
| Replace active fakes | «Настройки» | Выбор .bin для Discord UDP / Game UDP; оригинал не меняется |
| Update IPSet List | «Списки» → «Обновить IPSet» | Дополнительные пользовательские IP не теряются |
| Update Hosts File | «Списки» → предпросмотр → применение | Свой блок и backup; права администратора нужны только для записи |
| Check for Updates | «Обновления» | Официальный ZIP, SHA-256, установка, версии, откат |
| Run Diagnostics | «Обзор» → «Диагностика» | Только чтение BFE, служб, TCP и proxy; исправления остаются в upstream-меню |
| Исправления в Run Diagnostics: TCP timestamps, конфликты Killer/Intel/Check Point/Adguard и др. | «Оригинальное меню» → Run Diagnostics | Оригинальная логика не дублируется; может менять сеть и службы |
| Очистка кэша Discord Stable/PTB/Canary/Development | «Обзор» → «Кэш Discord» | Закрывать Discord нужно самостоятельно; папки переименовываются для восстановления |
| Standard tests / All configs | «Проверка стратегий» | Оригинальный `utils/test zapret.ps1`, отдельное окно, ручной выбор режима |
| DPI checkers | «Проверка стратегий» | Та же оригинальная PowerShell-утилита |
| Свои домены | Редактор `list-general-user.txt` | Сохраняется вне официального пакета |
| Исключения доменов | Редактор `list-exclude-user.txt` | Сохраняется вне официального пакета |
| Дополнительные IP/CIDR | Редактор `ipset-extra-user.txt` | Добавляются к актуальному IPSet при подготовке рабочей копии |
| Исключения IP/CIDR | Редактор `ipset-exclude-user.txt` | Сохраняется вне официального пакета |
| Цели Standard tests | Редактор `targets.txt` | Если override ещё не сохранён, используется оригинальный `utils/targets.txt` |
| Новые/редкие функции service.bat | «Оригинальное меню» | Доступны из установленного upstream-пакета без релиза GUI |
| Win7-драйвер, WinDivert hide и ручные исправления из FAQ | Оригинальные инструкции upstream | GUI не отключает защиту ОС/антивируса и не заменяет драйвер автоматически |

Не все действия upstream имеют отдельную форму в GUI. Полное функциональное покрытие достигается сохранением оригинального меню и тестовой утилиты. Эти внешние окна имеют исходную консольную навигацию; результаты сетевых проверок показываются там, а не интерпретируются GUI.

Настройку Secure DNS пользователь выполняет через ОС/браузер по официальной инструкции upstream. GUI не меняет DNS, VPN, proxy, firewall или TCP timestamps автоматически.
